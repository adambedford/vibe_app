| D6 | 2026-11-11 | Each game on its own subdomain of a separate user-content domain, in an iframe sandboxed with `allow-scripts allow-same-origin` and a strict CSP; all platform access through the host; the games domain stays off the Public Suffix List for now | Proposed | Same-domain iframes; injecting the SDK into a WebView (v0); fully opaque sandboxed frames; listing the domain on the PSL | Untrusted code never shares an origin or context with the app. Opaque frames would stop Chrome caching the engine, and PSL listing would stop Chrome sharing it across games |
