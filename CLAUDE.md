# Project notes for AI assistants

This repo is a social app whose feed is made of small, AI-made web games that people play inline and can create or remix themselves.

- The design lives in `docs/design/`. Read `docs/design/00-overview.md` first.
- Record significant decisions in `docs/decisions.md`, with the alternatives considered and why.
- `docs/legacy-v0-review.md` explains what was kept from the earlier attempt (commit `3371204`) and what was dropped.
- There is no code yet. When code starts, it is TypeScript throughout, in a pnpm workspace.
